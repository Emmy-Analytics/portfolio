# Emmy Portfolio V3 — Billie-inspired immersive direction

This is an original implementation inspired by the interaction language of the Billie Framer reference:
- Full-screen editorial hero
- Oversized typography
- Floating data card with mouse-follow motion
- Image strip treatment
- Hover-to-reveal project previews on desktop
- Responsive mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Dark/cream section transitions
- Data-inspired visuals

It does NOT copy Billie’s original assets or text. Replace the placeholder visuals with Emmy's real project screenshots.

## Run
```bash
npm.cmd install
npm.cmd run dev
```

## First edits
Open `src/main.jsx` and replace:
- placeholder email
- LinkedIn URL
- GitHub URL
- project descriptions/links

Then add real project images under `public/images/`.
